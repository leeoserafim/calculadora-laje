<h1 align="left">Calculadora de laje treliçada</h1>

###

<p align="left">O software foi desenvolvido para simplificar e agilizar o cálculo preciso de materiais necessários para montagem de lajes treliçadas. Ele gera arquivos completos com todas as informações do cliente e a quantidade exata de materiais, facilitando o envio do pedido para produção. Os dados podem ser salvos em formatos .txt e .xls, além de permitir a abertura de arquivos .xls gerados anteriormente para ajustes ou edições.<br><br>A interface é fácil de usar: o usuário insere o tipo de treliça (H8, H12, H16, H20 ou H25), a largura do preenchimento, a largura do cômodo ou a quantidade de vigas desejadas, o comprimento das vigas e, quando necessário, a quantidade de barras de aço adicionais em cada vigota. O software atualiza automaticamente as tabelas com base nas informações fornecidas, mostrando em tempo real a quantidade e o tamanho das vigas, além das barras de aço adicionais. Um relatório completo é gerado ao lado, detalhando a metragem quadrada, metro linear, metro linear de aço adicional, quantidade de EPS, tavelas e malhas para cada tipo de laje. Na parte inferior, os botões permitem adicionar ou remover vigas, calcular, salvar o cálculo e abrir arquivos .xls para revisão e edição.<br><br>Este programa foi desenvolvido com o objetivo de agilizar o processo de cálculo de materiais para orçamentos e automatizar a lista de vigas e tamanhos, facilitando o envio dos pedidos para produção nas fábricas.</p>
